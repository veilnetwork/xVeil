# Чтение журнальных сегментов при проверке собственных устройств

2026-11-04. Продолжение [разбора стоимости подписи и сохранения](../history-signature-work-2026-11-04/README.md).
Mailbox собственных устройств не добавляется. Все данные стендов синтетические;
публикуются только агрегаты, без исходных журналов, идентификаторов и ключей.

## Атрибуция

Test-only census помечает выполнение production `myOtherDevices` через Zone
и считает завершённые RPC, начатые в этом контексте. Возвраты и исключения
сохраняются; произвольные Zone values отбрасываются. Это контекст инициатора,
не эксклюзивное время: несколько callers могут ожидать одну unfinished read.

Первый замер имел пустые context-счётчики: provider после инициализации заменял
обёрнутый callback. Для атрибуции он не засчитан, хотя data oracle прошёл.
Fixture теперь следует за rebind `groupServiceProvider`, оборачивает каждый
реальный resolver один раз и закрывает свою подписку при остановке. В последующих
прогонах обязательны ненулевые счётчики callback на A и B.

Контроль без изменения production-кода, native Mac/JIT, 2000 сообщений:
на B в recovery window 9734 `kv.readLogBatch`, из них **9576** начались в
контексте own-device lookup; их inclusive await — 15,989 с. Всего 2714
завершённых lookup с 47,655 с inclusive await. Повторные проверки уже
установленного delivered не были причиной этих ожиданий.

## Изменение

Раньше `loadFiles` объединял метаданные, но читал payload каждого файла
отдельной серией worker RPC. Добавлен optional `AsyncLogGroupReader`:
до восьми независимых exact-ID групп и **64 записей суммарно** на запрос.
Worker последовательно читает только заданные ID и проверяет лимит байтов
каждой группы до чтения следующей записи/группы. Ошибка или отсутствующая
запись не позволяет перейти к последующему payload.

`AsyncFileStore` читает inline cohort ограниченными волнами, в том числе
через границы файлов. Продолжение одного файла получает остаток его лимита,
а ID разворачиваются лениво, только на ближайшие 64 записи. Для streamed,
неполных/неизмеримых/неподдерживаемых метаданных и backend без capability
сохранён последовательный путь. Предварительный разбор не превращает ошибку
поздних метаданных в ранний отказ до чтения предыдущего файла.

Каждый вызов заново читает метаданные и payload. Принятые данные, membership,
список адресатов, ответы проверки доступа и ключи между вызовами не сохраняются.
Сетевой протокол, лимиты истории, ratchet/durable barriers не менялись.

## Проверки

- Контроль числа payload RPC падал на прежнем пути: два запроса вместо одного.
- Порядок, дубли запрошенных файлов/ID, пустые записи, недостающий блок,
  отказ перед следующим файлом, лимит файла через две волны, malformed metadata,
  mutable request lists, переполнение лимитов и fallback проверены без таймингов.
- 579 тестов прошли; один env-gated native case был skipped и затем отдельно
  выполнен с проверенными библиотеками и fixture — прошёл. Analyzer: чисто.
- Отдельный реальный worker: 50 чтений трёх неизменных файлов по 60 000 байт
  в A/B/A, тот же контейнер и те же bytes. Plain payload RPC: **150 / 0 / 150**,
  grouped RPC: **0 / 50 / 0**. Длительности чтений: **362,213 / 337,816 / 339,164 мс**.
  Между контролями есть разброс; заметное isolated wall-time ускорение не доказано.

## Полные native-прогоны

Production библиотеки Veil/HV заморожены и совпадают по SHA с предыдущим
этапом. Квалификация: настоящий SIGKILL B во время первичной догрузки,
непустая sparse-копия на диске до сети, запуск без A/C, затем возвращается
только A, runtime offer нескольких prefix proofs, финальный restart B без
источников. Требуются точные ID/order/source positions/delivered и отсутствие
дублей/invalid snapshot/completed-history retry.

| Прогон | Строк на диске после crash | Сходимость после готовности API A | Payload RPC на B |
| --- | ---: | ---: | ---: |
| Контроль с рабочей атрибуцией | 1565 | 56,232 с | 9734 plain |
| Grouped 1 | 1569 | 51,213 с | 1766 plain + 1731 grouped |
| Grouped 2 | 1572 | 51,221 с | 1749 plain + 1716 grouped |

В каждом прогоне все 2000 строк сошлись и сохранились после запуска без
источников. Ни одного пропуска/дубля или несогласованного финального порядка.
По последнему boot A: 76/75/75 входящих запросов истории. Фактические частичные
копии различались; poll около пяти секунд. Наблюдаемое уменьшение — примерно
один интервал опроса, **не точная причинная оценка в процентах**.

Все стенды закрыты, собственных процессов/слушателей нет, runtime удалены;
исходники/зависимости и выбранные native artifacts проверены после прогона.
Новый путь покрыт обязательным ненулевым `kv.readLogGroups`. Это локальный
Mac/JIT, не квалификация Android/AOT, реальной сети или полной multi-device матрицы.

Общая задержка догрузки остаётся открытой. Эта серия предшествует отдельному
исправлению hash checks в hidden-volume; его исходники и новая библиотека
не участвовали в приведённом сравнении. Push, релиз и установка APK не выполнялись.
