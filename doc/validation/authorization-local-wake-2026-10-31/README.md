# Локальное уведомление для checkpoint авторизации

SDK: локальный коммит `c46d94db`, без изменения release version.

Хост больше не обязан ждать периодический tick, когда native узнаёт новый
проверенный документ: пустое локальное IPC-событие запускает checkpoint.
**Событие не является ACK и не даёт права использовать документ.** Экспорт
снимка, защищённая запись всех его частей и ACK точной revision сохранены.

Путь: verified floor change → runtime EventBus → существующий transport event
stream → handle той же личности → PeerAuthorizationPersistence. Новый kind=6,
payload пуст; ни идентификаторов, ни документов, ни типов пользовательского
трафика. Событие не идёт в overlay/на реле. C function ABI и его fingerprint
не изменились: расширен payload-протокол существующих opaque IPC events.

Notifier вызывается после освобождения floor lock; повтор неизменённого
документа, отвергнутая подпись и ACK не создают новых уведомлений. До host
restore обычный runtime не посылает эти host hints. Weak-ссылка на EventBus
не создаёт цикла жизни runtime. Только одна активная hint-работа и одна
отметка pending удерживаются на владельца; 200 hints не создают 200 flush.
Revision, пришедшая во время I/O, проверяется следующим проходом.

При ошибке I/O hint-повторы ждут периодического retry. Опрос **1 с оставлен**
для ошибок и потери best-effort events; частота idle polling не увеличена.
После подписки выполняется catch-up. При поздней привязке transport есть
дополнительный catch-up, чтобы не потерять состояние из промежутка между
start владельца и bind транспорта. Малое окно асинхронной установки native
event handler по-прежнему покрывается периодическим backstop.

Close отменяет подписку, присоединяет начатый checkpoint и делает финальный
снимок до закрытия native handle. Поздний callback не использует закрытый
handle. Ошибки источника/записи фиксируются константным обезличенным сообщением;
исходный exception/stack не копируется в журнал.

## Проверки

Красный контроль на прежнем владельце с новым optional change-source:
после hint сохранение не начиналось до timer. На кандидате gate входа в
настоящий storage достигнут до любого продвижения виртуальных часов;
заблокированный commit не допускает ACK. Burst во время I/O даёт ровно два
экспорта для двух revision и ACK `[2, 3]`, без очереди из 200 задач.

Проверены потерянный до подписки hint, retry после ошибки, окончание stream,
присоединение заблокированного I/O на close и отсутствие обращений после close.
Исходный polling-only тест с **999 мс** при мгновенном fake store сохранён:
он квалифицирует fallback, не обещает такую же задержку native сети.

Черновик close-теста под fake_async не продвигал completion Future отмены
broadcast-подписки. Отдельный минимальный probe воспроизвёл то же поведение
без xVeil; это не считалось дефектом приложения. Close проверен обычным async
тестом с явными I/O gates и ожиданием его Future, без временного порога.

**171 Dart-тест прошёл, 0 skipped**: authorization/ratchet/security/rollback
и SDK event types. Targeted analyze изменённых source/stand файлов: no issues.
**2150 основных Rust-тестов прошли, 18 ignored отдельно**: IPC, runtime,
proto, FFI. Дополнительный вывод одного child test уже входит в FFI-счёт и
повторно не прибавлялся. Runtime notifier-тест проверяет reentrant export,
тишину для invalid/replay, pending до durable ACK и отказ старого ACK.

**3 native security-теста прошли**: signed revocation после restart,
изоляция двух runtime и encrypted multi-batch failure/reopen. В native-тесте
дополнительно проверен catch-up при bind к пустому stream после появления
состояния. Это не авторизация пустым событием: verdict проверяется отдельно.

## Native A/B

Один frontend с новым обработчиком в обеих фазах; A — прежняя библиотека
SDK `081bb6d1`, B — новая библиотека с producer уведомлений. Это изоляция
доставки hints, **не A/B всего исходного Dart patch**. SHA библиотек после
codesign и source/fixture SHA проверены; ABI fingerprints совпадают.

12 разных native личностей, cached production-PoW fixtures, свежие encrypted
containers/instance keys, TCP full mesh/DHT, настоящие crypto/ratchet/host
authorization. Legacy group без epoch encryption, roster out-of-band.
Один Mac/JIT host/диск; это не multi-device и не Android/Windows qualification.

|---|---:|---:|---:|---:|---:|
| A1 | 4296 | 2455 | 2344 | 2706 | 0 |
| B1 | 4259 | 2607 | 2357 | 3437 | 64 |
| A2 | 4223 | 2471 | 1728 | 2942 | 0 |
| B2 | 4179 | 2475 | 2627 | 2721 | 64 |

| B3 | 4394 | 2879 | 2406 | 2278 | 64 |

Медианы A/B: **4223/4259, 2471/2607, 2063/2406, 2838/2721 мс**.
Общего ускорения нет; по двум следующим сообщениям медиана выше.
Эти данные не доказывают устранения всех секунд доставки. Причинные ветви
могут различаться; контроль фиксированного времени/дерева не выполнен.

У всех 12 runtime B реально получены уведомления: восемь по 5, четыре по 6;
это не hint только последнему зарегистрированному runtime. От получения hint
до первого следующего native version read: медианы **60–83 мс**, максимумы
**271–396 мс**. Это включает очередь за начатым I/O, может относиться к уже
сохранённой revision и не измеряет весь интервал от native изменения до ACK.

## Проверка без периодического backstop

Только в отдельном test fixture pollEvery установлен в **1 час**. Четыре
сообщения дошли всем 12, получены 64 hints. Явные flush других путей не
исключены: это проверка отсутствия зависимости от periodic timer в данном
сценарии, а не утверждение, что вся работа запущена исключительно событиями.
Production по-прежнему использует 1 с.

A/B выше сделан до финального catch-up при bind. Это startup-добавление
квалифицировано отдельно на окончательных source bytes: три native security
теста и повтор stand с часовым backstop. В окончательном stand наблюдаются
**12 bootstrap catch-up hints + 64 в окне сообщений**, все четыре сообщения
у всех 12 ровно один раз. Его времена не подменяют A/B до этой добавки.

Итого девять stand-запусков, **36 сообщений без дублей/пропусков**. Для каждого
wire-copy проверены enqueue/send/receive, восстановлены критические цепочки;
timing drops нет. Все девять host завершились, по 12 listeners освобождены,
cleanup_errors пусты; временные контейнеры удалены. Телефон и public relays
не изменялись. Rust build/test использовали mount watchdog внешнего target.

В одной форме приватного metadata унаследованный `native_library_sha256`
описывал baseline. Реально выбранная библиотека проверялась до запуска по
отдельному proof и фиксировалась как `selected_native_sha256` и независимый
`frontend-source.native_sha256`; отчёт использует эти поля. Добавлен отдельный
selected-library proof, исходные записи не переписаны в доказательство успеха.

Анонимный отчёт продукта не расширен IDs/путями/документами; adapters только
тестовые. Остаются доставка/синхронизация и multi-device матрица. В A/B
group handling критических путей следующих сообщений занимал **0,84–1,83 с**,
а cold transport-call→callback суммарно по трём логическим переходам —
**1,50–2,10 с**: снятый polling wait не объясняет весь этот остаток.
Без push/релиза.
