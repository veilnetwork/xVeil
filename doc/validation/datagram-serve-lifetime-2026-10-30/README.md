# Время жизни datagram-выдачи — 2026-10-30

База xVeil — `509ea91a`, SDK не изменялась. Проверка касается fallback через
pieceRequest/pieceChunk, а не управления перегрузкой анонимного stream.

## Подтверждённый дефект

Весь `_serveAuthorizedPieces` был обёрнут в `Future.timeout(50 s)`. Таймер
освобождал `_servingNow`, даже если чтения успешно завершались и получатель
регулярно запрашивал данные. Исходная задача при этом продолжала работать:
`Future.timeout` не отменяет её. Следующий запрос запускал вторую выдачу того
же content ID, хотя слот предназначен для единственного читающего курсора.

В воспроизведении 32-КиБ файл требует восемь чтений по 10 виртуальных секунд.
Каждое укладывается в существующий шаговый предел 15 секунд. Повторные запросы
каждые 5 секунд поддерживают интерес получателя. На исходном коде после общего
дедлайна одновременно работают два чтения вместо одного.

Второе воспроизведение удерживает чтение source metadata. Через 51 виртуальную
секунду новый запрос успешно получает восемь chunks. После освобождения старой
подготовки исходный код отправляет ещё восемь, хотя его слот давно освобождён.
Это повторная выдача на транспортном уровне, не доказанный дубль сообщения в UI.

## Исправление

Предел 50 секунд ограничивает только подготовку: metadata, выбор/проверку
источника, проверку наличия независимого blob. Просроченный результат не входит
в цикл отправки. Если он принёс собственный проверенный descriptor, этот lease
закрывается; заимствованный исходный handle ему не принадлежит.

Начавшаяся выдача сохраняет слот до действительного завершения своего цикла.
Чтение и отправка каждого chunk по-прежнему ограничены 15 секундами; ответ GONE,
финальная фиксация ratchet и закрытие собственного handle тоже ограничены.
Receiver-interest проверяется между batches: после прекращения запросов выдача
останавливается и следующий запрос может запустить её снова. Dispose проверяется
перед batch и после чтения, чтобы поздний результат read не публиковал payload
после начала закрытия личности.

Это ограждение продолжения задачи, а не отмена платформенного I/O. Уже начатое
чтение/запись может завершиться позднее; уже отправленные данные не отзываются.
Долгая подготовительная проверка источника может продолжаться до возвращения
результата, но больше не запускает просроченную отправку. Лимиты доступа к папкам,
проверки CID, ratchet/ACK, wire и правила реле/mailbox не ослабляются.

## Проверки

Пять сценариев через настоящий MessagingService, authenticated datagram ingress,
FakeKvLogStore и fake_async; без реального ожидания 50/80 секунд:

| Сценарий | Проверяемый результат |
| --- | --- |
| Регулярные запросы, восемь чтений по 10 с | Один активный read; восемь chunks строго по одному, все bytes совпали |
| Подготовка завершается после таймаута и успешного повтора | Всего восемь chunks, просроченная задача не добавляет ещё восемь |
| Получатель прекратил запросы | Выдача останавливается; новый запрос вновь работает |
| Один read не вернулся в шаговый предел | Остальные chunks выдаются; поздний read не отправляет пропущенный chunk; повтор работает |
| Dispose во время read | Поздние bytes не отправляются |

На исходном `509ea91a` окончательная матрица дала **3 failed / 2 passed**:
параллельное чтение, поздняя повторная выдача и отправка после dispose
воспроизвелись; два контрольных сценария уже работали. Исправление даёт
**5/5 passed**. Общий прогон 12 файлов дал **163 passed**, эти пять уже входят
в 163. Analyze двух изменённых Dart-файлов — без замечаний; format/diff check
прошли.
Итоговые числа и SHA-256 проверенных исходников — [summary.json](summary.json).
Дескриптор, полученный после подготовки с просроченным дедлайном, имеет явный
finally-подобный cleanup в коде; отдельного физического зависшего opener-теста
эта матрица не содержит.

## Границы

Это воспроизводимый дефект datagram fallback. Связь именно с пользовательским
зависанием на 33% не доказана. Причины задержек анонимного stream, начальных
5,5 секунд и проблем Windows/Android остаются открытыми. Физической проверки
этой Dart-правки на телефоне ещё нет. Стендовые приложения, звонки и серверы
не запускались. Raw logs приватны. Коммит без подписи, push/релиза нет.
