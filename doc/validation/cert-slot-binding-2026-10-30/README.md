# Привязка ML-KEM сертификата к запрошенному экземпляру — 2026-10-30

Базовая SDK `e8e54d42`, исправление `bdd149c4`. Подтверждён отдельный дефект выбора сертификата:
корректная подпись удостоверяла содержимое, но несколько путей не проверяли,
что подписанный `instance_id` соответствует запрошенному DHT-слоту. Более новая
запись другого экземпляра той же личности могла попасть в результат/кэши либо
вытеснить подходящую запись до окончательной проверки адреса.

## Исправление и регрессии

Пара `(node_id, instance_id)` проверяется до сравнения свежести и публикации
в mirror/store/cache. Исправлены обычный локальный lookup, обычный сетевой
lookup, сбор сертификатов семейства и выбор кандидата для заданного экземпляра.
Подписи, signed validity, выбор самой свежей подходящей версии, durable
authorization floor и ratchet-барьеры сохранены. Wire, relay QoS, mailbox,
таймауты и лимиты запросов не менялись.

Тесты используют настоящий подписанный документ, подписанный реестр и два
корректно подписанных сертификата одной личности: нужный экземпляр версии 3
и другой экземпляр версии 99. Чужая запись лежит под ключом нужного слота;
в четвёртом тесте она приходит через настоящий `SessionTxRegistry`.

| Путь | Прежняя SDK | Исправленный код |
| --- | --- | --- |
| Локальный обычный lookup | Возвращает другой экземпляр | Отказ без заполнения cert/EK/ratchet-key кэшей |
| Сетевой обычный lookup | Принимает другой экземпляр | Отказ, cert store и кэш пусты |
| Lookup семейства | Включает другой экземпляр | Запись пропущена, один unknown device, store пуст |
| Lookup конкретного экземпляра: нужная локальная v3, чужая удалённая v99 | Чужая версия вытесняет нужную; результат отсутствует | Выбрана нужная v3, mirror правильный, чужая запись не сохранена, pending очищен |

Все четыре регрессии упали на прежнем коде; остальные 44 resolver-теста прошли.
После исправления прошли все 48. Проверки основаны на результате и состоянии
хранилищ/очередей, без порога времени.

Полный runtime: **742 passed, 11 ignored**. FFI: **326 unit passed, 2 ignored**;
5 ignored doctests отдельно, внутренний subprocess не прибавляется к общему
счёту. FFI flags: `--no-default-features --features
node-embedded,production-seeds,packet-tunnel`. Clippy runtime `--lib --tests --
-D warnings`, rustfmt и diff-check прошли. Внешняя ФС target проверялась до и
во время сборок; потери mount не было. Числовая сводка: [summary.json](summary.json).

## Физическая проверка перед этим исправлением

Проверка текущих исходников выявила отдельный незакрытый сбой. Она выполнялась
**до правки привязки сертификата**, на xVeil `8a7abf8b` / SDK `e8e54d42`:
новый Dart на обоих концах, macOS JIT и Android profile/AOT. Телефон Blackview
работал через Wi-Fi. Второе Mac-устройство его личности оставалось offline;
активный Mac принадлежал другой личности. Звонки не запускались.

Mac → Android: один файл **3 145 979 байт** дошёл с правильным SHA-256 за
**7,906 с**, включая запрос и проверку хеша. Первая наблюдаемая запись проверенных
частей — 5,717 с, максимальный промежуток между наблюдаемыми записями — 1,103 с.
Опрос Android примерно раз в секунду; эти интервалы не измеряют сетевую тишину.

Android → Mac: API отправителя принял предложение файла, но оно не появилось
в истории получателя за **120 с**. Загрузка на Mac ещё не начиналась. В native
журнале отправителя есть обычные отправки на адрес личности, завершавшиеся
примерно через 30 с; путь отмечен `unknown`. Это не доказывает зависание до
планирования: часть family-пути возвращается до установки этого маркера.
Конкретная стадия ожидания и связь с найденным дефектом сертификатов не доказаны.
Проверены хвостовая выборка истории, отсутствие dropped devlog и смещение часов;
полная серия остановлена после одного успешного файла. Это **не десять успешных
передач**, не A/B и не закрытие «33%» или репорта Windows 10.

Оба native-артефакта собраны заново с production-фичами, SHA артефактов сохранены
в приватном доказательстве происхождения; дерево Dart сверено по файлам. Android
подписан прежним QA-сертификатом. У `libdartjni.so` изменился только build-id:
после обнуления этой note бинарники совпали целиком, остальные native-библиотеки
вне Veil совпали по SHA. Исходная QA APK восстановлена и сверена по SHA; основной
клиент/данные не менялись. Необязательная облачная проверка именно этой QA APK
отклонена в системном диалоге; глобальные настройки проверки не менялись.

Запущенные тестовые Mac/Android приложения закрыты, их процессы завершены;
временные настройки/forward/владение стендом восстановлены. Реле не менялись.
Raw-журналы, адреса, content IDs, данные профилей и абсолютное время оставлены
в приватных файлах; публичная сводка содержит только агрегаты и кодовые версии.
Push/релиз не выполнялись. Исправлен локальный дефект выбора сертификата;
физическая односторонняя доставка остаётся открытой до повторной проверки.
