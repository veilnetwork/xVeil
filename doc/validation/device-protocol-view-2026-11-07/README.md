# Служебное состояние устройств независимо от скрытия строк на экране

Подтверждены две ошибки в `deviceSyncState` / `deviceSyncRecords`.

1. Чтение служебного журнала применяло локальное «скрыть прочитанное».
   После истечения окна из проекции исчезало `identityDoc` с адресом
   физического устройства; routing терял этот адрес, хотя подписанная
   запись оставалась в журнале. Ошибка чтения настройки отображения также
   могла прервать служебный lookup.
2. Чтение вызывало `_now()`, увеличивающий логический счётчик записей.
   Повторные запросы при неподвижных часах делали событие с будущей датой
   эффективным раньше реальной границы допуска.

Оба служебных представления теперь отключают только локальный presentation
filter и читают wall clock через `_clockNowMs()`. Обычное экранное скрытие
сохранено. Подписанная retention, lifecycle, membership, signature/chain,
author provenance и фильтр будущих событий продолжают работать. Свежий
`load` журнала сохранён; кэш прав, дополнительный TTL и mailbox не добавлены.

## Доказательство

Шесть новых проверок используют настоящий GroupService/fold и тестовое
хранилище: три вида чтения после реального скрытия строки, отказ локальной
настройки и два представления с будущим событием. Тест сначала убеждается,
что экранная проекция действительно скрыла строку, а raw journal её сохранил.
Для каждого служебного чтения: **0** обращений к presentation preferences,
**1** свежий read заголовка группы.

Независимые mutations на окончательной fixture:

- Возврат локального фильтра при сохранённом исправлении часов: три ошибки
  проверяемого значения и одна инъецированная ошибка чтения настройки.
- Возврат `_now()` при отключённом presentation filter: две assertion-red.
  После 512 чтений неподвижные часы не должны применять будущее событие;
  реальное продвижение часов на 200 мс допускает точную skew boundary.

В обеих mutations нет timeout как признака провала, исходник кандидата
восстановлен побайтно. Начальные ошибки компиляции и fixture с недостаточно
продвинутыми часами исключены из доказательства. Исправлена fixture;
семантика production screen view ради теста не менялась.

Связанные suites: **617 passed / 11 skipped**, analyzer двух изменённых
файлов без замечаний. Skipped не считаются прошедшими. Native qualification
и ограничения приведены в [агрегатах](summary.json).

## Native crash / offline qualification

Отдельные Mac/JIT процессы A/B одной личности и C другой, private relay
island на loopback, SDK `c6699c28` и прежний проверенный native HVS. Последние
Dart-исходники frozen на весь прогон; CLI, FFI и HVS сверены по SHA, после
receiver restart две живые worker mappings подтвердили выбранные библиотеки.
Публичные seeds и discovery отключены; sibling mailbox не включён.

Получатель принудительно завершён после наблюдения 623 из 2000 записей.
Оба источника выключены: до подключения к сети сохранены все 623 ID, тела,
статусы delivered и 573 уже имевшиеся canonical positions. Возвращён только
A; в итоге сошлись все 2000 ID/тел/статусов/позиций и порядок без дублей и
history retries. Ещё один cold boot B при выключенных источниках до сети
подтвердил сохранность всех 2000 строк. Неполная промежуточная проекция не
выдаётся за итоговую сходимость.

До полной сходимости — 67,459 с от начала наблюдения, включая crash и
перезапуски; после возврата `start(A)` — **40,924 с**. Это один correctness
прогон без A/B: причинный выигрыш общей скорости не заявлен, задача задержек
догрузки остаётся открытой. Обращения `ownDevices/kv.get` здесь включают и
другие настройки; нулевое число presentation reads доказано отдельными
адресными тестами, а не приписано всему RPC census.

1509 frozen source inputs/native SHA неизменны; все 26 известных PID вышли,
29 портов освобождены, временный runtime удалён, SDK/HVS исходники прежние.

Это отдельный подтверждённый дефект служебного чтения. Он не объявлен причиной
NETCALL-01, прежней жалобы Windows или ускорением всей догрузки. Проверки
телефона в соседних отчётах использовали прежний frozen QA AOT и не являются
квалификацией этих Dart-изменений. Push/релиза нет.
