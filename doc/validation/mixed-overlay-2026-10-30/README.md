# Групповой оверлей: граница смешанных версий

**По прямому указанию пользователя совместимость со старыми версиями отложена
и не является условием текущего релиза.** Пользователь сообщил, что оба реальных
пользователя обновятся. Зафиксированное ниже ограничение не объявлено исправленным.

До этого указания выполнены три native-прогона 12 участников. Идентификаторы
подобраны двумя шестёрками, между которыми прежний XOR-селектор не строит связей.
Использованы реальные GroupService, MessagingService, подписи, ratchet с
сохранением авторизации, hidden-volume и TCP-loopback. Старый и новый native SDK
загружались в отдельных процессах; каждый процесс обслуживал свою часть узлов.
Низкая сложность PoW и обход криптографических проверок не включались.

| Состав | Сообщение из первой шестёрки | Из второй | Оба сообщения на участниках |
|---|---:|---:|---:|
| 12 текущих | 12/12 | 12/12 | 12/12 |
| 11 текущих, один старый на границе первой шестёрки | 6/12 | 12/12 | 6/12 |
| Один текущий, 11 старых | 6/12 | 6/12 | 0/12 |

Версии: прежний xVeil `v0.13.93` с точным SDK `09bf0da3`; текущий xVeil
`2edb8dc3`, Dart SDK `3b891089`, native core `08b67a6e`. Обычные сторонние Dart
зависимости взяты из доступного текущего package cache: это не побайтовое
воспроизведение старого опубликованного приложения. ABI старой библиотеки
проверен по контракту соответствующего SDK; SHA библиотек зафиксированы приватно.

Все текущие участники увидели два сообщения за 5,354/6,606 с, без логических
дублей. Для неполной смешанной доставки время окончания наблюдения **не является
временем сходимости**. Четыре явных запроса синхронизации единственного нового
участника в третьем случае недостающие копии не восстановили. Топология каждого
варианта рассчитана его настоящей production-функцией выбора соседей; наблюдаемая
достижимость совпала с ней. Исправления совместимости в этом цикле не внесены.

Границы: один Mac, JIT-хост, legacy-группа без шифрования эпох, заранее сохранённые
принятые контакты, без реального handshake контактов, onion-реле и смены состава.
Это подтверждение конкретного ограничения смешанной топологии; не полная
multi-device квалификация и не проверка текущей эпохальной группы в интернете.

Публичные агрегаты: [summary.json](summary.json). Сырые журналы и идентификаторы
остались в каталоге владельца вне репозитория. Все процессы стенда завершились,
локальные слушатели освобождены; телефон и реле не менялись. Собственные архивы
старых исходников и отдельный Cargo target удалены после остановки проверки.
