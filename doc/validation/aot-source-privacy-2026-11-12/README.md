# Нейтральные пути Dart AOT — 2026-11-12

Продолжение [проверки, обнаружившей домашние URI](../windows-microphone-aot-2026-11-12/README.md).
Локальные QA-артефакты не публиковались. Это квалификация способа сборки,
а не объявление всех релизных платформ готовыми.

## Подтверждённый способ

Физическая копия проекта размещается в отдельном нейтральном каталоге с доступом
только владельцу. После locked offline pub setup корни локальных packages
указывают на эту копию, внешние зависимости — на нейтральные directory aliases
существующих исходников. На Windows используются junctions без Developer Mode,
на POSIX — symlinks. Полную Flutter SDK копировать не понадобилось: исходники
его packages также доступны через aliases.

`scripts/aot_package_roots.py` выполняет только последний шаг подготовки:

```sh
python3 scripts/aot_package_roots.py \
  --source-project ORIGINAL_PROJECT \
  --staged-project NEUTRAL_PROJECT \
  --aliases-root NEUTRAL_DEPENDENCIES
```

Это **не** средство создания копии проекта и не готовый release wrapper.
Нужно заранее перенести локальные SDK packages, необходимые native workspace,
assets и закреплённые библиотеки; выполнить locked pub setup для plugin links;
после remap компилировать с `--no-pub`. Повторный pub get перегенерирует config
и требует повторного remap. Исходный package config не меняется.

Сохраняются package names, packageUri, languageVersion и зависимости.
Обфускация не применяется. В отдельной настоящей Dart AOT-пробе внешняя
библиотека прочитана через alias; исключение сохранило имя функции и читаемый
`package:` stack frame без домашнего URI.

Скрипт проверяет границы путей, доступность package roots, коллизии aliases и
нейтральность назначения. Конфигурация заменяется атомарно только после подготовки.
Ошибки возвращаются классом без исходного текста/путей. Девять проверок прошли
на macOS и Windows 11: в том числе literal junction target с кавычкой и `$()`,
неуспешная подготовка, отказ атомарной замены и повреждённая схема. Повторный
запуск на реальной Windows package configuration стабилен. Первое применение
к вручную подготовленной карте нормализовало URI; за idempotence принят именно
следующий запуск. Проверки добавлены в CI.

## Сборки и проверка байтов

| Артефакт | До, домашних source URI | Нейтральная сборка | Объём проверки |
|---|---:|---:|---|
| Windows profile AOT | 1827 | 0 | Весь комплект: 41 файл, 95 530 885 байт |
| Android arm64 profile APK | 1316 | 0 | Все 609 членов APK, 118 016 108 байт |

Кроме syntax-based URI scan, весь Windows-комплект проверен на фактический
путь владельца в UTF-8/UTF-16 и URI-варианте; совпадений нет. В Android APK
также нет фактического домашнего пути сборщика. Это конкретные проверки
этих артефактов, не универсальный поиск любых секретов или кодировок.

Windows runtime frontend соответствует `3e78499a`, media source — `83a54e35`.
Перенесены сверенные 807 canonical inputs и 20 текущих overlays. Свежая media
DLL, сохранённые Rust FFI и hidden-volume проверены по SHA. Windows VPN helper
собран из полной SDK workspace с отдельным target; предыдущие build directories
не использовались как доказательство происхождения новой библиотеки.

В Android core SDK/HV/media побайтно совпадают с ранее проверенным QA APK;
перенесён актуальный Dart frontend. У остальных native libraries изменился
только JNI plugin: Gradle пересобрал его. APK содержит точный результат своей
strip-задачи; проверены три фактических compilation units из Pub package,
build model и совпадение всех 311 публичных exports с сохранённым plugin.
Равенство всех native файлов намеренно **не** заявляется. Оба network assets
совпали с входами новой сборки. Rust для Android повторно не собирался.

## Запуск и восстановление

Нейтральная Windows-сборка открыла отдельную холодную копию тестового контейнера:
`locked → ready`, `realStack=true`, затем штатный POST `/lock`. После этого
своё приложение и scheduled task остановлены, копия удалена. Исходные QA
данные, canonical source и прежние native libraries сохранили проверенные SHA.
Нового звонка и проверки слышимости в этой серии не было.

Нейтральный Android APK установлен только как отдельное QA-приложение.
Подтверждены живой процесс, hook и настоящий экран onboarding. Создание
контейнера, звонки и разрешения этим smoke не проверены. Приложение остановлено
и удалено, собственный forward снят; SHA основного APK не изменился.
