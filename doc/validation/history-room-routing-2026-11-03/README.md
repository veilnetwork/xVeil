# History backpressure должен смотреть на адрес очереди

2026-11-03. Локальная правка без push/релиза, native pins, установки на
телефон и изменения публичных реле.

## Подтверждённое несовпадение

`serveHistoryAsk` проверял `pendingFramesFor` для `otherDeviceIds`, а delta
sender использует `addressableOwnDevices`. Первый список отражает registry,
второй — актуальные transport-адреса, включая объявленный master. Outbox
индексируется точным `peer.hex`, без нормализации identity → device.

Есть два варианта отказа. Если registry возвращает identity-слот, проверяется
пустая alias-очередь вместо полной device-очереди. Если sovereign authority
owner исключён из registry полностью, список на linked-источнике может быть
пустым: его master device присутствует только в адресном списке, и ни одна
очередь не проверяется. Последний вариант подтверждён precondition-снимками
на настоящем native-стенде; это не отсутствие master announcement.

Поведенческий unit использует настоящий GroupService и resolver с подписанным
fixture-журналом. На старом цикле callback получает identity вместо master.
Дополнительная sovereign-регрессия воспроизводит пустой registry: старый код
возвращается без единого вызова queue callback. Оба красных контроля падают
на адресе/наличии проверки, не по ошибке сборки или таймауту.

## Исправление

Цикл ожидания выделен в `awaitDeviceHistoryRoom`, который вызывается самой
production-проводкой replay. Он читает `addressableOwnDevices` после каждого
ожидания. Predicate отмены проверяется также после чтения адресов и включает
смену активного GroupService. Время ожидания две минуты, poll 500 мс, backlog
room 128 и replication cap не менялись. Auth/ratchet/durable barriers,
подписи и wire format не менялись. Это не кэш авторизационного состояния.

Проверены alias/master queue, пустой sovereign registry, замена объявления
master во время ожидания, revoke и отмена при удержанном чтении. Широкий набор
**506 passed, 3 skipped**, затем 5 focused routing-тестов (включая добавленный
sovereign-вариант) и analyzer прошли. Сигнатурный verifier в unit — fixture;
реальный Outbox проверяется отдельным native-сценарием.

## Native-проверка

Три процесса A/B/C, B — linked-источник. После реального link и получения
master announcement A останавливается. B ставит настоящие group snapshots
в durable Outbox до 128+ кадров к объявленному master. Счётчик проверяется
и через MessagingService, и чтением durable registry через live storage
worker. Никакого открытия живого контейнера вторым процессом нет.

Probe вызывает тот же helper с настоящим `messaging.pendingFramesFor`,
фиксирует, вернулся ли он до отмены при полной очереди, и отменяет ожидание.
Это file-controlled тестовый код, не приложение/HTTP endpoint. В stdout и
публичную запись попадают только агрегаты; raw snapshots/IDs/ключи остаются
в приватном каталоге и не экспортируются пользователям.

Два первых запуска не зачтены: стенд ошибочно требовал наличия identity в
registry, а реальная sovereign-модель исключает authority owner. Оба
терминально завершены и очищены. Добавлены precondition-снимки без IDs и
проверка возможности завершиться без queue callback; это изменение оснастки,
а не ослабление проверяемого инварианта.

| Метрика | Прежний цикл | Исправленный |
| --- | ---: | ---: |
| Реальные snapshots, поставленные в очередь | 15 | 15 |
| Pending к actual master в MessagingService | 135 | 135 |
| Pending к actual master в durable storage | 135 | 135 |
| Pending к identity alias | 0 | 0 |
| Registry delivery recipients | 0 | 0 |
| Проверена actual master queue | нет | да |
| Возврат до отмены при полной очереди | да | нет |
| Чистое завершение после отмены | да | да |

Контроль с прежним циклом специально упал на assertion проверки фактической
очереди. Summary записан до assertion; таймаут/ошибка подготовки не принимаются
за красное воспроизведение. Исправленный код прошёл тот же сценарий. Контрольный
цикл извлечён из прежнего production closure без изменения выбора recipients;
это не автономная копия алгоритма в тесте. В сравниваемых исходниках отличается
только `lib/state/device_sync_bridge.dart`.

Один Mac, JIT, worker/HV, native signing и изолированное loopback-реле.
Публичные discovery/seeds выключены. SDK/CLI/FFI заморожены на ранее проверенном
`eb644a83`, HV одинаков — это Dart-квалификация, не последних transport-правок.
1395 frozen-файлов и native artifacts сверены до/после. После каждой фазы
проверены выход 18 собственных PIDs и освобождение 18/19 портов. Живых своих
процессов/слушателей нет, runtime-контейнеры удалены. Два незачтённых precondition
запуска также завершены и очищены с независимым cleanup-подтверждением.

Кандидат восстановлен после контроля и сверён с источником успешной native-фазы.
Пользовательские контейнеры, телефон, Windows и публичные реле не менялись.
Никаких raw IDs, ключей, профилей или correlation hashes здесь не опубликовано.

Это устранение обхода backpressure, не обещание времени доставки и не измерение
сквозного ускорения. Большая история в этом цикле не мигрировалась; прежняя
цифра 41,5 с относится к предыдущему pacing A/B/A. Дополнительное чтение
адресов при room poll имеет цену, которую нужно квалифицировать на большой
истории. Полная матрица multi-device/offline/crash, физический handover и
остальные открытые случаи сохраняют статус.
