# Один журнал для приёма compact-delta

Подтверждена и устранена лишняя работа при приёме групповой data-delta без
manifest: восстановление manifest, проверка членства и merge повторно читали
один и тот же зашифрованный журнал. **Общая задержка доставки остаётся открытой**:
уменьшение числа чтений подтверждено, устойчивое ускорение всего пути — нет.

## Изменение и границы

Для уже хранимой обычной группы компактная data-delta проходит под mutation
gate: загружается полный журнал, проверяется hash manifest, выполняются прежняя
политика допуска и настоящий `_ingestSnapshot` на этом же bundle. Приватный
общий код политики обслуживает и обычный публичный `allowStrangerGroupSync`;
публичный API не позволяет передать bundle как доказательство полномочий.
Fold использует те же проверки подписей и исходные поля состояния.

Не вводится долгоживущий cache доверенного состояния. Незавершённая церемония,
связанная с этим source/gid, остаётся на исходном пути с pinned manifest.
Device markers, adoption seeds, control snapshots и неизвестные форматы
сохраняют прежние маршруты. Отсутствующий/повреждённый журнал не становится
новой группой. Документы, подписи, epoch keys и durable apply не обходятся.
Receipt и overlay-пересылка выполняются после освобождения gate, по-прежнему
читают актуальное состояние и ждут durable enqueue, а не первую сетевую попытку.
Приоритеты, численные лимиты, wire и настройки реле не менялись.

## Как проверено

- Исходный control: два красных теста по реальному числу чтений header
  (контакт **2**, неконтактный участник **3**). Итоговый путь делает **1** чтение
  для обоих; авторизация неконтактного участника остаётся отдельной проверкой.
- Проверены локальная запись во время ingress, очередь revoke перед приёмом,
  отказ чтения с последующим повтором, отсутствующий segment, неверный hash,
  отсутствие членства и незавершённая церемония с другим promised manifest.
- Собственный первый кандидат пропускал последнюю проверку. Новый тест был
  красным на кандидате и зелёным на старом коде; до коммита добавлен fallback
  в исходный путь связывания. Это не объявляется ранее выпущенным дефектом.
- Отдельный красный тест следующего кандидата поймал повторную загрузку
  журнала из проверки допуска; итоговый private core использует уже загруженное
  под gate состояние. Границы source/gid и политика pending/own-device/index/ACL
  сохранены в общем коде.
- Финальные **448 тестов прошли, 0 skipped/ignored**. Включены настоящие native
  проверки XVSB hash/adopt, chunked sovereign credential и XVRC recovery.
  `flutter analyze` для production-файла и двух timing adapters: **no issues**.

Замеры находятся только в `test/support`: Zone передаёт синтетический номер
кадра вложенным storage RPC; payload, group/node ID, ключи и пути не записываются
этими адаптерами. В продукте нет тестового переключателя или обхода admission.
Вложенные интервалы перекрываются и не суммируются в критический путь. Отсутствие
публичного таймера `group.snapshot` на новом приватном пути не означает пропуск
merge: выполняется тот же `_ingestSnapshot`, его результат проверяется историей.

## Native-серия

Один и тот же frozen release SDK `081bb6d1`, один Mac/JIT host, 12 native TCP
узлов с DHT, настоящие MessagingService/GroupService, контейнеры, подписи,
ratchet и durable host authorization. Legacy-группа без epoch encryption;
roster передан вне сети. 12 cached production-PoW identities одинаковы,
контейнеры/instance keys свежие; маршруты и их порядок не фиксированы.

Контроль frontend — `9bb1c645`. Чередование A1/B1/A2/B2/A3/B3; четыре сообщения
от разных источников 0/6/5/11, поэтому «последующие» не равны повтору той же пары.

Медианы всего receive: **442/435/469 → 441/428/385 мс**. Это интервалы обработки
всех копий, включая повторные, а не атрибуция критического пути сообщения.
`timing_dropped=0` во всех запусках.

После серии исправлены только lint: четыре single-statement `if` получили
блоки, timing adapter использует super parameters. Production-diff этого шага
сохранён и проверен; предикаты и тела не менялись. Точные финальные исходники

сверен до/после smoke. Сам SDK не менялся и не пересобирался.

узлы остановлены, 12 listeners освобождены, временные контейнеры удалены.
Контрольное переключение frontend защищено SHA-проверками и отдельным rollback
watcher; в workspace восстановлен кандидат, watcher завершён без конфликта.
Ранние серии до pending-guard и shared admission — прототипы, в эту таблицу
не включены. Телефон и production-реле не менялись. Без push и релиза.

## Что дальше

Несколько секунд доставки не объяснены одной стоимостью чтений. Следующий
разбор связывает одну копию конкретного сообщения: durable relay enqueue →
начало реальной transport-send → native seal/admission → callback получателя →
ratchet/app ingress → первая видимость. Особенно важно отделить ожидание
фоновой отправки от её исполнения и от повторных копий. Multi-device матрица
пока не квалифицирована; ранее отложенные неповторяющиеся жалобы не возвращены
в активную очередь без нового воспроизведения.
