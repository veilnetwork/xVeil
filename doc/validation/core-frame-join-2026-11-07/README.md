# Недоставка после перехода на мобильную сеть: кадры уже на Core

Продолжение [TCP-захвата](../tcp-transit-detail-2026-11-07/README.md).
Те же immutable SDK `c6699c28` и qualified QA AOT, Poco / Android 16 и Mac,
один отдельный testnet Core на TCP 443, P2P denied. Production не менялся.
Core ограничен 128 MiB / 30 минутами и пониженным CPU/IO weight; это стенд,
а не квалификация нагрузки production. Новых Rust-библиотек для этих вызовов
не собирали. Текущие Dart-изменения в AOT не заявлены как проверенные.

## Четыре квалифицированных вызова

| Сеть Poco | Направление | Пять последовательных свежих RX с обоих концов после place | Затем |
|---|---|---:|---|
| Wi-Fi | Poco → Mac | 3,699 с | 35 с, конечные пять срезов свежие |
| Wi-Fi | Mac → Poco | 3,662 с | 35 с, конечные пять срезов свежие |
| Мобильная | Poco → Mac | **22,651 с** | 35 с, конечные пять срезов свежие |
| Мобильная | Mac → Poco | Не достигнуто | **Нет exact incoming за 45,305 с** |

Wi-Fi отключён **между** разговорами, когда оба QA call slots пусты.
Оба мобильных сценария начинались уже на validated cellular. Внутри
разговоров переключения не было. RX age, packet count, running/worker и
exact call ID проверялись вместе; смена epoch/обнуление счётчика не считались
восстановлением. Это цифровой приём, не слышимость человеком. Успех третьей
строки не отменяет её долгой подготовки и отказа следующего вызова.

## Сквозное наблюдение непрозрачного кадра

Заранее проверены живые admin subscribers на **Core и Mac**, только family 3.
Операторский capture budget — 1000 событий/с на peer, не изменение сетевых
лимитов. Исходная same-UID admin-аутентификация сохранена. Взяты полные JSONL:
14 354 Core events и 6174 Mac events; plaintext events **0**.

Для source → Core сопоставляется SHA-256 того же ограниченного зашифрованного
preview, который уже пишет source trace. Получены 24 точных ingress matches
для sparse Poco и 5220 source observations Mac (две стадии одного кадра).
Это счёт whole capture, включая исключённую подготовку, **не** число
аудиопакетов четырёх вызовов.

На relay меняется 32-байтовый next-hop prefix. Core RX → Core TX → Mac RX
сопоставляются по остальному 224-байтовому preview, включающему полный
content ID. В Core RX и TX нет неоднозначных ключей; каждому из 6739 Core TX
соответствует RX. Header `VME1` используется только для диагностической
выборки, не для доверия, приоритета или маршрутизации. Сырые previews,
идентификаторы и хеши остаются приватными.

Три SSH clock probes дают консервативный offset interval шириной 1,486 с.
Для таблицы ниже берётся **внутренняя** часть каждого call window, которая
лежит внутри него при любом измеренном offset. One-way latency не выводится.

| Внутреннее окно | Источник / выборка | Core RX | Core TX witness | Mac RX witness |
|---|---|---:|---:|---:|
| Wi-Fi, Poco → Mac | Poco, media-marked | 591 | 591 | 591 |
| Wi-Fi, Mac → Poco | Poco, media-marked | 819 | 819 | 819 |
| Мобильная, Poco → Mac | Poco, media-marked | 490 | 490 | 490 |
| То же | Mac, media-marked | 818 | 540 | Не снималось на Poco |
| Мобильная, Mac → Poco | Mac, остальные Forward | **137** | **0** | Не снималось на Poco |
| То же | Poco, остальные Forward | **90** | **90** | **90** |

В последнем окне одновременно **44** наблюдения local reliable pressure к
телефону: queue depth до **176**, повтор через **10 мс**, head — neutral
`Delivery/Forward`, 652 байта. В полном захвате есть TCP flush stalls и
retransmissions. Из этих данных нельзя ещё назначить конкретный TCP socket
или admission branch причиной каждого отсутствующего исходящего кадра.

**Локализация стала уже:** Mac-пакеты реально поступают в Core при работающем
обратном направлении и накоплении очереди к Poco. Но отсутствие capture TX
само по себе не является доказательством drop: subscriber/rate-limit могут
пропускать наблюдения, а TX означает выбор транспорта, не доставку. Не доказано
и соответствие конкретного encrypted Forward именно call-offer. Поэтому
NETCALL-01 открыт; нельзя объявить его устранённым или свести к микрофону.
[Все анонимные агрегаты](summary.json).

## Следующая инструментальная граница

Прежняя `local_reliable_pressure` не называла отказавший маршрут. После
физической серии добавлен opt-in snapshot **последнего reliable-child Full
в текущем turn**: `pressure_route=child`, свободные actor slots, actor/record
buffered bytes, completed/received records. Иначе — `pressure_route=other`,
что не утверждает конкретную причину. Snapshot читается только при RT trace;
лог остаётся с прежним throttling. Дополнительных идентификаторов/данных
сообщения нет. Admission, очередь, таймеры, wire и cipher ownership прежние.

Эта диагностика ещё **не была** в описанной физической серии. Следующий
захват должен отличить заполненный child от иных retry gates, а уже затем
обосновать исправление. Уменьшение таймаутов или смена носителя наугад здесь
не вводились. SDK `97dc1295`: **697 session tests passed / 8 ignored**,
отдельный source commit без push. Сборка шла на проверенном внешнем FS под
mount/free-space watchdog; потери mount не было. Это проверка новой
диагностики, а не её физическая квалификация. Результат записан в
`summary.json` отдельно.

## Исключённая подготовка и завершение

- Первый Core observer запущен с неправильным UID: admin отказал. Повтор
  выполнен с реальным service UID; защиту не обходили.
- Приложение не сохраняет временный TOML. Для Mac observer использован
  валидированный отдельный минимальный config с существующим owned socket.
- Один вызов стартовал до готовности Mac observer: остановлен и **исключён**.
  Все четыре строки таблицы — после фактической проверки обоих subscribers.
- Phone observer не дал ACK. Контроль подтвердил отсутствие stdin roundtrip
  через ADB exec-out; последующий shell health probe тоже не дал admin reply.
  Захват на телефоне и пятая попытка вызова **не заявляются выполненными**.
- Поиск `VPN` во всей строке ошибочно совпал с capability `NOT_VPN`.
  Вывод отозван; исходный raw `Transports` подтверждает Wi-Fi. VPN не менялся.

Полный PCAP — 35 921 packets / 138 flows — скопирован и size/SHA проверен
до cleanup. 1533 SDK и 1480 frontend inputs неизменны **во время серии**;
исправленные harness versions заморожены отдельно для Wi-Fi и mobile phase.
Локальные subscribers, probe/logcat, phone nc и контрольные cat процессы
завершены. QA APK, normal APK и старый контейнер сверены по SHA; сеть,
разрешение микрофона, stay-on и обе P2P policies восстановлены. Mac потребовал
SIGKILL после grace; выход и порты проверены, bundle codesign повторно проверен.
Отдельные observer/capture/Core services остановлены, свой runtime/config/
бинарник удалены, production PID/exe/config прежние. Push/релиза нет.
