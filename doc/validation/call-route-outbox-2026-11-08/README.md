# Очередь устаревших состояний маршрута звонка

Подтверждён отдельный дефект control-plane: каждый `transportInfo` имел
собственный durable frame ID, поэтому после новой маршрутной информации
Outbox продолжал повторять прежние состояния до ACK/TTL. Получатель уже
фильтрует старые timestamps, но лишние повторы занимают путь доставки.
В предыдущем физическом захвате были поздние transportInfo; этот механизм
не объявляется доказанной причиной паузы NETCALL-01.

## Исправление

Flush удаляет только строго более старые чистые снимки transportInfo того же
звонка и адресата, когда точная более новая строка ещё существует в durable
Outbox. Проверяются wire kind, envelope frame ID, canonical ID, timestamp,
route и allowlist полей. Capture, forwarding, неизвестные поля и ordered seq
не очищаются. Равные timestamps сохраняются. Явный отказ от P2P сохраняется,
если новый снимок не содержит такой же отказ.

Удаление атомарно проверяет peer и все bytes старых строк и сохранённого
преемника. Исчезнувший после ACK преемник не вставляется заново. Операция
привязана к исходной сессии контейнера; входные bytes копируются до await.
За flush допускается до четырёх групп, до 64 старых строк на каждую.
При отказе или неизвестном исходе коммита captured старые строки не отправляются
в текущем проходе; следующий проход заново читает authoritative queue.

Wire, ACK, подписи, ratchet, квалификация маршрута и live send не менялись.
Уже принятые SDK отправки не отзываются. Другие Storage без optional capability
продолжают прежнее поведение. Mailbox не добавлен.

## Проверка и границы

Два focused assertion-red до реализации. Финальные 12 focused cases входят
в **185 passed / 7 skipped** восьми связанных файлов; пропущенные не зачтены.
Покрыты отказ до коммита и потеря его ответа, ACK преемника во время очистки,
разные адресаты/звонки, равные stamps, capture и P2P withdrawal, неизвестные
поля, ordered seq, неверный ID/kind, bounds, byte/peer witness и поздний ACK
старого ID. Реальный HVS: **1 passed / 0 skipped**, удаление переживает
close/open, ACK преемника не приводит к его восстановлению. Использована
ранее квалифицированная release HVS eceb9158, SHA-256 библиотеки
`ac39b38a59e770f78f3216421cd3f915036ca6ac07f17eba1c797c4cb123cb3a`.
Первый native запуск не скомпилировался из-за пропущенного импорта fixture;
он не зачтён как red или native qualification. Analyzer семи Dart files чист.

Физического доказательства сокращения NETCALL-паузы пока нет. Предыдущие
28,6 с audio RX age не приписаны этому дефекту. Push/релиза нет.
