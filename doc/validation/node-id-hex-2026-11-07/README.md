# Разбор идентификаторов на пути догрузки истории

Продолжение [профилирования догрузки](../routing-announcement-prefix-2026-11-07/README.md),
база — `7dcfe2d0`. В предыдущем профиле B функция `NodeId.fromHex` присутствовала
в 408 из 3838 main-isolate samples, `GroupMessage.fromJson` — в 484.
Это inclusive frames, не складываемые доли wall time. При каждом чтении группы
те же идентификаторы разбирались заново: 32 substring + 32 `int.parse` на ID.

## Изменение и сохранённый контракт

[Декодер](../../../lib/core/ids.dart) читает ASCII hex digits напрямую по code
units. Канонические lower/upper/mixed-case строки не создают подстрок по каждой
паре. Для остальных пар остаётся прежний `int.parse`, включая его принятие
знака/whitespace и точные ошибки. Отрицательное значение по-прежнему оборачивается
при записи в Uint8List. Удаление ASCII-пробелов и проверка длины прежние.

Нет кэша идентификаторов, строк или авторизации. Каждый результат по-прежнему
получает собственные bytes; присваивание mutable bytes одному ID не меняет
другой. Подписи, ACL, ratchet, freshness и чтение durable headers не менялись.

[Проверки](../../../test/node_id_and_seen_test.dart) сравнивают результат или
тип/текст ошибки с независимой копией прежнего декодера: **32768** ASCII-пар
в начале/конце ID, все byte values с разным регистром, Unicode whitespace,
суррогаты, знаки, неправильная длина и отдельное владение буферами.
9 focused tests; в связанном наборе **508 passed / 11 skipped**, включая эти 9.
Analyzer трёх изменённых Dart-файлов чистый. Два независимых mutation controls
дали assertion-red: неверное значение hex-буквы и отказ от legacy fallback.
Candidate после каждого восстановлен побайтно. Первый legacy probe завершался неожиданным FormatException; он не
засчитан в два assertion-red. Итоговый контроль заменяет fallback значением 0
и падает на сравнении bytes принятого legacy ID. Старый decoder семантически
эквивалентен; correctness-red на нём здесь не заявляется.

## Воспроизводимый AOT-замер

[Скрипт](../../../scripts/bench_node_id_hex.dart) использует только synthetic IDs,
сравнивает прежний decoder с production factory и проверяет одинаковый checksum.
По пять A/B/A triplets на четыре профиля, 100000 ID в каждой фазе; всего
6000000 измеренных разборов. Одинаковые входы, полный NodeId с прежним владением
bytes, без одновременного native-стенда. Тайминговых assert нет.

```sh
TMPDIR=/private/tmp/ dart compile exe scripts/bench_node_id_hex.dart -o /private/tmp/bench-node-id-hex
/private/tmp/bench-node-id-hex
```

[Агрегаты](summary.json) содержат все пять triplets и median по каждому профилю.
Это замер стоимости **разбора ID**, не скорости сети или всей догрузки.

Median для 100000 разборов, мс:

| Профиль | A₁ | Candidate | A₂ |
|---|---:|---:|---:|
| lower | 53.648 | 12.808 | 53.675 |
| mixed | 54.130 | 13.758 | 54.932 |
| spaces | 135.008 | 88.902 | 132.815 |
| legacy | 55.195 | 16.973 | 55.101 |

Первичные и итоговые замеры согласуются; итоговый executable проверен по SHA
и исходникам, private hashes не публикуются.

## Native: crash, offline и сохранность полной истории

Один Mac, три отдельных process hosts A/B/C и три loopback Core. A/B — одна
личность; C — другая. Native FFI/CLI на immutable SDK `c6699c28`, HVS прежний;
текущий SDK source `37f6bb08` не выдаётся за пересобранный binary. Между этим
прогоном и прежним квалифицированным стендом native artifacts одинаковы.

B получает историю из 2000 сообщений и принудительно завершается SIGKILL:
771 наблюдавшаяся запись, включая тела и delivered, сохранена до появления сети
после рестарта при выключенных A/C. Затем возвращается только A; **2000/2000**
ID/тел/delivered/итоговых canonical positions и порядок сходятся без дублей,
completed-history retries 0. Ещё один cold boot B при выключенных источниках
подтверждает все 2000 сохранённых записей. Oracle требует положительных counts;
одинаково пустые истории не считаются сходимостью.

После `start(A)` возвратилось полное наблюдаемое состояние за **25,567 с**.
**Общее ускорение не доказано:** parent проверяет историю с интервалом 5 с,
результат включает разрешение этого наблюдателя; миллисекундная разница с
прежними 25,681 с не является доказательством выигрыша. Объём уже принятой
истории и обратной работы тоже отличается. Native CPU samples inclusive,
это не A/B wall-time experiment.

Остаток между последней wire-частью и следующим запросом — median **262,743 мс**
в 57 пригодных парах. Query → последняя часть — median **88,403 мс**.
Повторный request исключён, не засчитан как полный уникальный ответ.
Следующий участок — обработка страниц и повторные чтения/фолды device journal;
медленная догрузка остаётся активной.

1509 frozen source inputs и actual library mappings после аварийного рестарта
проверены. 34 собственных PID завершились, 51 порт освобождён, runtime root
удалён. Сырые профили, пути, IDs и журналы приватны. Это JIT/loopback qualification,
не Android AOT/WAN и не полная multi-device матрица. NETCALL-01 остаётся открытым,
Poco отсутствует в ADB. Нового sibling mailbox, push или релиза нет.
