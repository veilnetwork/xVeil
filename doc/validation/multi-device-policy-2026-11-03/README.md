# Own-device mailbox остаётся отключённым

2026-11-03. Владелец повторно подтвердил: «Не надо подключать mailbox для
мультиустройств». Это ограничение модели v1, не незавершённое исправление,
которое разрешено обходить альтернативным названием relay-хранилища.

Текущий код `_MessagingMailboxDelivery.maybeStash` отказывает own-device
адресату до seal/deposit. Существующий тест `nothing for my own device goes
into the mailbox` прошёл на текущем Dart. `doc/MULTIDEVICE-DESIGN.md` также
отделяет app-level device group от native instance registry и предупреждает,
что production mailbox seal выбирает один freshest instance, а не все
устройства. Простое снятие guard не обеспечило бы получение копии B.

Когда A и C одновременно offline, а B ещё не держит недостающие сообщения,
получение B без другого доступного владельца данных не требуется от v1.
Сохранённая на B история должна оставаться доступной локально; после возврата
держателя недостающей истории требуется восстановление связи и сходимость.
Именно последнее, включая crash/reconnect, остаётся в активной очереди.

Этот цикл не вводит mailbox/relay-репликацию между собственными устройствами.
Contact-only mailbox, формат шифрования и роли реле не менялись. Прежняя
проверка 100 сообщений с C offline и A online остаётся действительной;
доступность при всех источниках offline не переобъявляется её результатом.
