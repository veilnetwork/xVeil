# Blackview ↔ Mac: текущий AOT и восстановление Wi-Fi

Poco снят владельцем; запланированный mobile-handover запуск отменён до
установки APK, запуска Mac и изменения сети телефона. Его временные Core
собраны и удалены с независимой сверкой production. Взамен доступен Blackview
без SIM. Проверка ниже — Wi-Fi и полный обрыв Wi-Fi, **не Wi-Fi → Cellular**.

## Происхождение сборок

Оба клиента исполняли Dart `460d74e2` с одинаковым digest `lib/`, profile AOT.
Authenticated `/health.build` у обоих совпал с compiler inputs до работы с
контейнером. На Mac проверен mapping полного `App.framework/Versions/A/App`,
на Android — SHA установленного APK и mappings AOT/Veil/HVS/media. Android
пересобран полностью; kernel не подменялся. Замороженные native payloads и
тестовые seed assets проверены побитно при упаковке: Android SDK bbcd967a,
Mac c8f4929b, два Core e974cebe. Это не квалификация одновременного обновления
всех native зависимостей.

На Blackview установлен отдельный, ранее отсутствовавший QA package. Новая
синтетическая личность создана через обычный onboarding, сертификат сохранён
через DocumentsUI и сверен по SHA. Начальный PoW выполнен без снижения
сложности. Реальные main и две прежние QA-установки не запускались тестом.
Перед звонками подтверждены transport-сессии обоих клиентов и обоих Core,
контакт установлен настоящими request/accept путями.

## Два relay-only звонка

P2P запрещён у обоих endpoints; call/native route оставались relay во всех
28 baseline и 139 reconnect samples. Аудиосчётчики росли в обе стороны.
Слышимость человеком, эхо и шум не проверялись.

| Наблюдение | Mac | Blackview |
|---|---:|---:|
| Baseline: максимальный наблюдённый native RX age | 334 мс | 60 мс |
| Reconnect: первое наблюдение RX age < 1 с после возврата команды включения Wi-Fi | 4,907 с | 4,328 с |
| Reconnect: максимальный наблюдённый native RX age, включая выключенную сеть | 9415 мс | 8821 мс |
| Reconnect: native RX age в последнем sample | 328 мс | 34 мс |

Между возвратом команд выключения и включения Wi-Fi прошло 5,091 с. Один и
тот же второй call оставался active во всех samples, аудио восстановилось
без переоткрытия звонка; media epoch внутри него оставался 3 на обоих концах
(в первом звонке — 1). Времена восстановления — дискретные наблюдения API,
не точное время первого пакета, session-ready или подтверждённого Wi-Fi
association. Наличие 9,4-с RX age не означает 9,4 с ожидания при готовой сети.

Все **10 fast ACK** исходных offer/answer/answerSelected/end вернулись:
0,201–1,580 с после source log; ordinary ACK тех же frame IDs —
0,379–11,328 с. Сравнение внутри часов соответствующего отправителя,
без межустройственной привязки часов. До двух fast retries; guards
provenance/consent/typed pending peer+frame не ослаблялись. Кольца devlog без
dropped rows. Это квалификация доступности fast-receipt path на второй
модели Android, не causal A/B и не общий предел задержки.

Final API call frames — **0/0**. Полные API Outbox totals — **1/0**: на Mac
один служебный `p2p`, поэтому все очереди пустыми не объявляются. Crash/reopen
и сохранность ACK после аварии не проверялись.

## Завершение и границы

Оба приложения завершены, процессы проверены. Новый QA package удалён
(исходное отсутствие восстановлено); собственный синтетический профиль
сохранён только в private архиве для следующей подготовки. Тестовый
сертификат убран с телефона, собственный ADB forward и Mac runtime удалены,
подпись Mac проверена. Исходные Wi-Fi/stay-awake настройки восстановлены,
хеши трёх существовавших APK совпали. Это проверка APK и ограничений действий,
не утверждение о полном побайтном снимке всех чужих данных.

Оба временных Core, observers, state/config/binaries/unit удалены; архивы
сверены по SHA, тестовые порты свободны, production PID/binary/config
независимо совпали. Raw IDs/keys/captures остаются private.

**NETCALL-01 открыт:** исходный mobile handover и слышимость этим стендом не
проверены. Новых source-фиксов в этом цикле нет; квалифицированы существующие
правки. Push и релиза нет. Машиночитаемые числа — [summary.json](summary.json).
