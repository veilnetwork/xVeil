# Сжатие: введённый пароль не должен теряться — 2026-11-11

**На Android воспроизведена и исправлена потеря одного пространства.**
Если пароль второй личности оставался в поле без отдельного нажатия
«Открыть и сохранить», прежняя кнопка «Сжать» его игнорировала. Native backend
получал только уже собранные пароли и удалял не включённое пространство.

Это подтверждённый конкретный путь потери данных. Он не объясняет целиком
исходный репорт «после сжатия оба пароля не работают»: в данном воспроизведении
открытая личность сохранилась, а скрытая перестала открываться. Исходный случай
отказа обоих паролей остаётся невоспроизведённым.

## Исправление

- Перед запуском проверяется оставшийся в поле пароль. При успехе он добавляется
  в список сохраняемых пространств; отдельное нажатие Add больше не обязательно.
- Неверный или повторный пароль останавливает запуск и показывает существующую
  ошибку. После нового master password повторно проверяется покрытие детей.
- Два события ввода до следующего кадра не запускают две одновременные пробы.
- Диалог связан с исходным IdentityLease. Поздний результат проверки после
  окончания сессии не добавляется в список и не запускает rewrite. Закрытие
  устаревшего диалога не выполняет парольное восстановление старой сессии.

Контроллер по-прежнему проверяет полноту roster и наличие reopen password.
Не добавлялись перечисление неизвестных скрытых пространств, plaintext-журнал
паролей или изменение формата native-контейнера.

## Проверки на Blackview

Blackview BV6600Pro, Android 11, отдельный «Compaction QA». Основное приложение
и его контейнер не использовались. Установлены профильные AOT-сборки с текущими
Dart-исходниками; два явно учтённых QA-only overlay добавляют синтетические
данные и точку остановки после native rewrite. Эти overlay в проект не входят.

Три native-библиотеки каждой сборки побайтно совпали с опубликованным APK
0.13.95. Для hidden-volume 2.7.0 Android SHA-256:
`0ff95b49afd4faf60bab127c064b8827520e7fb5e62d971d07dcfafef8dac4c2`.
Это квалификация storage/UI-пути, не всех возможностей Veil/media этой сборки.
Rust не собирался. Сиды стенда отключены; production-реле не менялись.

### Обычный сценарий и прерывание после rename

На базовом Dart `bcb3b99a` через настоящий AppController созданы скрытая
личность и открытая, вторая — после `startOver`. В каждой профиль, файл
70000 байт и 16 обновлений настройки. Использованы обычные Android Argon-
параметры; синтетические node configs заранее подготовлены, майнинг не измерялся.

1. Через диалог явно добавлены оба пароля. Сжатие завершилось; оба профиля,
   файла, последняя настройка и ID точны. После отдельного холодного запуска
   результат сохранился.
2. Следующее сжатие остановлено сразу после успешного возврата native-вызова,
   до продолжения AppController. QA-only wrapper сохраняет маркер и удерживает
   Future; production-код в этот момент ещё не выполняет remap/reopen.
3. До остановки подтверждены новый inode основного файла, отсутствие temporary
   sibling, `preparingNode`, отсутствие native stack и ожидающая операция.
   Процесс остановлен SIGSTOP (проверен статус T), затем `am force-stop`.
4. После force-stop inode и SHA контейнера совпали с зафиксированными перед
   ним. Свежий процесс открыл оба пароля: профили, файлы, настройки и ID точны.

Это process-kill после успешного native возврата. Потеря питания, участок
внутри rename и master/all-online roster этим контролем не проверяются.

### Потеря из-за неподтверждённого поля: до и после

| Сборка и действие | Скрытая личность | Открытая личность |
| --- | --- | --- |
| Базовая: поле содержит hidden password, Add не нажат, нажат Run | Больше не открывается | Открывается, данные точны |
| Исправленная: те же действия на свежем QA-контейнере | Открывается, данные точны | Открывается, данные точны |
| Исправленная: холодный запуск после этого сжатия | Открывается, ID сохранён | Открывается, ID сохранён |

Перед Run проверены непустое obscured-поле, один уже добавленный Open и
отсутствие Hidden в списке. Это проверка именно неподтверждённого поля.
Перед установкой исправления сброшены только синтетические данные принадлежащего
стенду пакета. Серия не является сравнением скорости одинаковых контейнеров.

Первый наблюдатель collection не увидел результат нажатия: при клавиатуре
кнопка Add имела только 5,2 пикселя видимой высоты. По живому UI проверено,
что действие снова доступно; клавиатура скрыта, продолжен тот же диалог.
Перезапись до этого не начиналась. Ошибка наблюдателя не засчитана как
успешный crash-прогон или отказ native-сжатия.

## Сборка и очистка

Первый QA-build остановился из-за недостающего импорта в частном overlay;
импорт исправлен до установки. Это ошибка стенда, не дефект приложения.
Подпись и байты SDK-компилятора проверены; временно изменённая метка quarantine
восстановлена побайтно после каждой попытки и повторно проверена в конце.
Native SHA и хеши Dart-исходников сверены до запуска обеих квалифицированных
сборок; различия entrypoint/hook учтены отдельно.

QA-пакет остановлен и удалён, его процесс и собственный log reader завершены,
собственный ADB-forward закрыт. SHA основного APK совпал с исходным.
Удалены синтетические контейнеры, временные проекты и build tree; сохранены
малые proofs/logs и один итоговый QA APK. Личные данные, адреса, device IDs,
пароли и сырые логи в репозиторий не внесены. Push и релиза нет.
