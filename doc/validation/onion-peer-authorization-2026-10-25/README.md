# Отзыв устройств при разрешении onion-маршрутов — 25 октября 2026

A и B — отдельные процессы личности X; C — процесс личности Y. Проверка
использует настоящий SDK, зашифрованные контейнеры и три локальных узла.
Включён анонимный режим, публичные сиды отключены.

## Подтверждённые находки

| Находка | Воспроизведение | Исправление |
| --- | --- | --- |
| Кэш маршрутов не учитывает уже наблюдавшийся отзыв устройства | Подписанное объявление остаётся допустимым после обновления общего состояния авторизации | Каждое чтение кэша повторно проверяет делегирование через общий монотонный `IdentityDocumentFloor` |
| Старый документ DHT восстанавливает маршрут отозванного устройства после перезапуска | Восстановленный отзыв есть, но локальная копия документа DHT ещё старая | Решение принимает сохранённое состояние авторизации; старый документ не откатывает его |
| Проверка привязки не сопоставляет личность декодированного документа с запрошенной | Корректно подписанный документ другой личности помещён непосредственно в локальный shard по чужому ключу | Добавлено явное сравнение личности; это усиление границы чтения, а не подтверждённая удалённая атака: обычный сетевой STORE уже проверяет ключ документа |

Три случая сначала воспроизведены на прежнем поведении: 3 падения, 4 положительных
контроля прошли. Корректный актуальный документ с отзывом уже отвергался прежним
кодом; дефект касался обхода этого решения через кэш или старое состояние.

Сетевые потребители используют существующее общее состояние авторизации,
включая сроки ключей, отзыв и подтверждение записи host checkpoint. При
нечитаемом хранилище или неподтверждённой записи делегированный маршрут не
выдаётся. Обновление делегированного объявления запрашивает и документ личности,
даже если старый документ ещё разрешает его подписанта. Локальное зеркало
восстанавливается из принятого нового состояния, а не из устаревшего ответа DHT.
Проверка применяется также к резервному списку объявлений mailbox; назначение
mailbox и разрешённые типы сообщений не расширены.

Формат протокола и FFI не менялся. Приоритеты реле не менялись. Производственных
тестовых обходов не добавлено; новый сценарий находится в `test/e2e/`.
