# NETCALL-01: новые короткие проверки одного relay-кандидата

## Наблюдение и изменение

В [предыдущей физической серии](../call-handover-current-aot-2026-11-08/README.md)
Poco закрывал relay-кандидата после одной неподтверждённой проверки. Старый
direct sender сохранялся до следующего retry/local rebuild, и приём на Mac
останавливался до 11,844 с. Три control cells из 600-мс наблюдения дошли до
Mac и были расшифрованы; первая — примерно за 185 мс, следующие позже срока.
На обратном пути есть подходящие по размеру/времени поздние control cells,
но без plaintext-token witness они **не объявляются точно соответствующими
echo**. Причина отказа кандидата полностью не атрибутирована.

Теперь переход P2P → relay сохраняет уже открытый кандидат максимум для
трёх последовательных коротких наблюдений вместо немедленного закрытия.
Каждый вызов штатного SDK начинает **новую** challenge с новым nonce и своим
прежним 600-мс budget. Старый просроченный ответ не становится успешной
проверкой следующей попытки. Максимум наблюдений — 1,8 с вместо 0,6 с;
подготовка/open до них не менялись. Это явный обмен: до 1,2 с дополнительного
ожидания неработающего кандидата за возможность квалифицировать уже
прогретый путь до следующего service retry. P2P upgrade остаётся с одной
проверкой.

После каждого await проверяются тот же call, peer/device, engine, epoch,
исходный channel и transport. Hangup/замена call не запускают следующую
попытку и не позволяют commit даже успешного позднего результата. Native
proof, consent, deadline, replay и endpoint binding не менялись; при полном
отказе кандидат закрывается прежним finally, старый engine не заменяется.
Liveness timeout и пятисекундный service retry не менялись.

## Проверки

Одна прежняя проверка вынесена в используемую production-функцию без изменения
поведения, затем выполнен red-run: три assertion failures (ранний выход,
пропуск второго успеха, отсутствие фиксированного лимита из трёх). Первый
запуск с ошибкой импорта не засчитан как red. После ограниченного цикла
**303 related tests passed, 0 skipped**, analyzer трёх изменённых файлов чист.
Gate-тест удерживает каждую попытку отдельным completer; время не является
oracle. Покрыты отказ всех попыток, успех первой/второй/третьей, отсутствие
повтора P2P upgrade, закрытие owner во время обоих исходов и native exception.

Физическая квалификация нового Dart/AOT **ещё не выполнена**. Исчезновение
11,8-с паузы, улучшение на мобильном провайдере и исправление первого
liveness timeout не заявляются. NETCALL-01 остаётся открытым.

SDK/Rust не менялись и не пересобирались. Push/релиза нет.
