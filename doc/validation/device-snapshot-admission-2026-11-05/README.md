# Проверка TTL после допуска снимка устройств — 2026-11-05

База `7b244b17`. Локальная правка без push/релиза, mailbox для собственных
устройств, native ABI, движков, APK и сидов.

## Подтверждение и исправление

Полный снимок мог пересечь TTL во время durable enqueue. До завершения этой
операции и после неё первоначальная отправка/повтор могли выпустить старое тело.
Восемь настоящих assertion-red на базе: single/chunked × awaited/queue-only ×
ordinary/native HVS. Gate удерживает завершение реальной записи, clock явно
пересекает TTL, проверяется фактический transport boundary, а не тайминг теста.

Для собственной группы источник теперь ставит блокировку передачи до enqueue.
Возврат producer означает durable admission. Отдельная bounded очередь валидирует
полную сохранённую копию и только затем допускает её к отправке. Проверка не
ждёт сеть и не вызывается из-под сериализованного lock производителя группы.
Неизменённый snapshot снимает блокировку; заменённый проходит ту же проверку
после своей записи. Отказ проверки остаётся fail-closed до следующего sweep.
Ошибки записываются в анонимизированном виде без тела, пути и исходного текста.

Устаревший результат фильтра не может разрешить следующую одновременную запись:
учитывается revision допуска и число пишущих операций. Отдельный counter-control
без проверки revision даёт два assertion-red. Закрытие присоединяет начатую
проверку и не отправляет её результат. Обычные группы сохраняют прежний контракт.

## Проверки

Scoped: **44 passed, без skip**, с явно выбранной worker/native HVS. Новая
матрица включает 14 случаев (7 native/7 ordinary): TTL admission, отказ и
повтор, close, concurrent admission. Два дополнительных теста с реальным
GroupService подтверждают освобождение producer lock до serialized фильтра.
Включены atomic transfer, прежние TTL journal/floor и replication expiry guards.
Unit signer синтетический; normal-provider/signer путь проверяется отдельно.

Широкая серия: **1508 passed / 56 conditional skipped**, 85 файлов. Пропуски
не считаются пройденными. Analyzer изменённых lib и всего test чистый.

Normal-provider/signer A/B/C TTL/Outbox стенд прошёл все пять gates:
живые тела в исходной mixed copy, ordinary cleanup, чистые остановленные
raw roots, доставка замены и сохранность cold B при offline A/C. Это регрессия
штатного пути, а не физическое удержание каждого проверенного storage future.

Test/driver/cleanup **0/0/0**; 27 PID / 27 портов проверены, своих процессов и
listeners не осталось, runtime удалён. 1459 source/test/package hashes и native
SHA неизменны, SDK clean. 142,605 с — время всего сценария, не latency/A/B.

## Границы

Этот фикс относится к полному durable admission и последующей локальной
валидации. Поздние ожидания native transport/fragmentation, полная матрица
смены TTL policy/skew и старые осиротевшие partial transfers не закрыты.
Ускорение доставки не измерялось и не заявляется.
