# Актуальный desktop AV и подпись macOS — 2026-11-11

## Что проверено

Две отдельные QA-личности на Windows 11 и macOS прошли взаимное подтверждение
контакта и обмен сообщениями. Все три контрольных сообщения присутствуют на
обоих концах с одинаковыми ID и статусом delivered. Это обычные контакты,
не связанные устройства одной личности.

На обеих платформах заново собран profile-AOT frontend из `cdecca85` с явно
учтённой правкой размещения журналов, описанной ниже. Использованы полный SDK
`8e317b53` и актуальные локальные media engines с проверкой source/binary SHA.
Windows runtime snapshot содержит 807 проверенных исходных файлов; временное
host CMake-дополнение для установленного ATL учтено отдельно. ABI gate не
обходился, SDK-заглушки и media test hooks не использовались. Управляющий
QA-канал включён отдельными compile-time opt-ins.

Прошли два настоящих звонка:

| Сценарий | Windows: прирост audio RX / remote video frames | macOS: прирост audio RX / remote video frames |
|---|---:|---:|
| Windows → Mac; P2P, 4 среза за 15,1 с | 342 / 156 | 280 / 303 |
| Mac → Windows; P2P запрещён, relay, 6 active-срезов за 25,1 с | 462 / 353 | 438 / 293 |

Это интервалы наблюдения внутри звонков, не полная длительность разговора.
В обоих сценариях росли также audio TX, video TX и счётчики доставки видео
декодеру; уровни входа/выхода были ненулевыми. В первом звонке Mac сначала
принимал с выключенным микрофоном, затем включены микрофон и обе камеры.
Во втором — video с самого начала. Фактический транспорт проверен на обоих
концах, а не выведен из выбранной политики. Между срезами активных звонков
не наблюдалось terminal-события; оба завершены управляющей командой.

Использованы реальные микрофоны и камеры. Тестовая фраза/аудиофайл не
подставлялись; PCM, видео и кадры в файлы не записывались. Числа не означают
отсутствия потерь, доказанного ускорения, субъективного качества или слышимости
человеком. Аватары и показ картинки в GUI этим не квалифицированы. Телефон
не участвовал. Исходный пользовательский случай **Windows 10 ↔ Android**
остаётся открытым: доступная Windows 11 не заменяет эту проверку.

## Подтверждённый дефект журналирования macOS

Инженерный журнал по умолчанию создавался рядом с исполняемым файлом,
то есть в `.app/Contents/MacOS`. Запись меняет sealed bundle, нарушает подпись
и блокирует последующую подпись сборки: это воспроизведено на настоящем QA app.
Это отдельный packaging/runtime дефект, не объяснение исходной AV-жалобы.

Теперь для стандартного macOS bundle оба журнала создаются **рядом с `.app`**.
Standalone commands и другие платформы сохраняют прежний каталог; явный
override, временный fallback, rotation и compile-time logging gates сохранены.
Состав анонимного экспорта не менялся, raw-инженерные трассы в него не добавлены.

Регрессионный тест создаёт настоящий ad-hoc подписанный bundle с инертным
Mach-O, пишет через оба штатных log sinks и проверяет подпись `codesign`.
На старом размещении падают два сравнения: расположение и проверка подписи
после записи. После исправления **16 связанных тестов прошли без пропусков**;
анализ двух изменённых Dart-файлов чист.

Настоящий macOS profile-AOT пересобран после удаления только собственного
прежнего внутри-bundle журнала в приватный архив. Подпись проверена после
unlock, обоих звонков и остановки процесса; внутри bundle журнал не появился.
Обычная пользовательская установка не заменялась.

## Сохранность и остаток

Для Windows использована холодная копия прежнего QA-контейнера и его prefs
в отдельный тестовый профиль. Оригинал не запускался одновременно; SHA исходных
контейнера/prefs до и после совпали. Новая копия не объявляется отдельным
связанным устройством. Финально сверены frontend sources и packaged DLL;
пользовательские данные и production-реле не менялись.

После звонков восстановлена эффективная P2P-политика contacts, оба контейнера
заблокированы. Windows app и временные tasks закрыты. Mac после завершённого
lock не вышел по SIGTERM и был принудительно остановлен после проверки владельца.
Его процесс и собственный SSH-forward отсутствуют; подпись осталась действительной.

Это локальная квалификация, **без push и релиза**. Public immutable media pins
ещё требуют актуальной пересборки. До выпуска остаются платформенные артефакты
и штатные release checks; AV на Windows 10/Android, слышимость человеком и
GUI-обновление аватаров этим раундом не закрыты.
