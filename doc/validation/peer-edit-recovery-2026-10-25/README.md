# Восстановление пропущенных редакций через собеседника

**Компонентные исправления проверены. Native-сценарий пока не пройден:**
после перезапуска B не расшифровывает ответы C. Эта ошибка остаётся открытой;
весь пользовательский сценарий восстановления завершённым не считается.

## Подтверждённые находки

| Находка | Воспроизведение до исправления | Состояние |
| --- | --- | --- |
| При равной версии C не возвращает отличающийся текст | Новый тест: ожидался один ответ, получено ноль | Код и компонентный тест исправлены |
| При равной версии теряется отличие только в inline emoji | Новый тест: ответ не формируется | Код и компонентный тест исправлены |
| При прежнем тексте новая версия редакции остаётся только в памяти | После ответа C в контейнере остаётся 7 вместо 99 | Версия сохраняется; проверено повторное открытие |
| При большей версии и том же тексте новые emoji не применяются | В проверке значений сохраняется прежнее изображение | Исправлено сравнение содержимого |
| Недопустимая версия отражённой редакции подавляет следующий запрос | После номера выше wire-предела настоящая версия 99 не возвращается | Недопустимый номер отклоняется |
| Полученная от собеседника редакция повторно доступна как собственное авторское событие | Отдельный тест на прежнем коде обнаруживает её текст в `loadEventsSince` | Сохраняется происхождение копии; автоматический replay запрещён |
| После перезапуска B не открывает ответы C | Native: C принимает окно из 100 сообщений и формирует ответы по 50; B пишет `ratchet kind=0: authentication failed` | **Открыто, криптографический контекст / адресация исследуются** |

Первые пять тестов и отдельная проверка авторского replay воспроизведены на
сохранённой копии Dart-исходников `e3a64bc2`, хеши которой сверены перед запуском.
Для emoji сравниваются сериализованные значения, а не экземпляры объектов.

## Что изменено

Запрос сверки дополнительно несёт хеши содержимого известных редакций. При
равной версии отправитель и получатель используют тот же выбор по SHA-256
текста с emoji, что хранилище, журнал устройств и собственные страницы истории.
Текст и версия читаются согласованно с ограниченным повтором снимка.

Новая версия сохраняется и при неизменном тексте. Прежняя временная карта
подавления повторных ответов удалена: перезапуск больше не забывает это знание.
Старые исходящие строки, ошибочно записанные под автором-собеседником, также
сохраняют логическую версию без продвижения его авторского потока.

Редакция, возвращённая собеседником, хранится как **отражённая копия**:
её номер участвует в выборе видимого состояния, но запись не утверждает
авторскую позицию и не выдаётся для повторной отправки. Этот признак сохраняется
в контейнере, зеркале и собственных страницах истории. Если своё устройство
передаёт ту же редакцию как авторскую, происхождение обновляется без изменения
текста и версии. Обратное понижение происхождения запрещено. Полученный текст
не публикуется как новая локальная редакция в журнал своих устройств.

При создании отражённой строки и при обработке очереди исключена её
автоматическая отправка как собственного сообщения. Обычные локальные и
аутентифицированные редакции сохраняют прежнюю отправку и подтверждения.

Метаданные запроса добавлены совместимо: старый участник игнорирует новое поле
и продолжает сверять строго большие версии. Исправление конфликта равных версий
через собеседника требует обновления обеих сторон.

## Проверки и открытый участок

* **537 тестов в 27 файлах прошли**, полный `dart analyze` — без замечаний.
* Проверены все 100 хешей в запросе с предельными допустимыми номерами версий,
  восстановление двумя ответами по 50 и отсутствие третьего повторного ответа.
* Проверены повторное открытие, происхождение копий на новом устройстве,
  повышение происхождения при той же версии и тексте, отсутствие обратного
  понижения, запрет правки входящей строки через own-echo и автоматической
  отправки отражённой строки.
* Native использует отдельные процессы A/B/C, действительную привязку B к A,
  настоящий SDK, зашифрованные контейнеры и изолированные локальные реле.
  A выключен во время восстановления B через C.
* Контролируемые конкурирующие редакции подготовлены только в остановленных
  контейнерах. Наблюдение за живым хранилищем добавлено исключительно в тестовый
  worker; новых производственных отладочных API или переключателей нет.
* Native остановился по заранее установленной границе **180 секунд**. Полное
  окно до C доходит, ошибки размера кадра не наблюдалось. Ответы не открываются
  на B, поэтому последующие этапы восстановления и повышения происхождения
  на настоящем транспорте пока не квалифицированы.
* После красного прогона проверены **7 process groups и 11 PID**: живых
  участников нет, контейнеры стенда удалены. GUI-приложения и телефон в этом
  цикле не запускались.

Для следующего шага нужно сопоставить ratchet-контексты получателя и отправителя.
Версия о смешении физического адреса B и адреса личности при отсутствии прямой
сессии пока является гипотезой. Снятие криптографической проверки или повторное
знакомство устройств не считаются исправлением.

Отдельный кандидат со старым namespace 3 закрыт по истории проекта: его чтение
сознательно исключено коммитом `7c2dbb292` с принятым сбросом истории ещё в июле.
В текущем коде исправлен только оставшийся неверный комментарий об этом.

Полная матрица multi-device, длительный offline, Windows, физические звонки,
старые архивы и все варианты повторной установки этим отчётом не закрываются.
SDK и hidden-volume в этом цикле не изменены; релиз и push не выполнялись.
В отчёте только агрегаты и хеши программ: runtime ID, адреса, ключи, содержимое
пользовательских сообщений, пароли, контейнеры и сырые журналы не публикуются.
