# Временное управление серверным узлом без SSH — 2026-11-11

Реализованы отдельный Linux-помощник `veil-connect`, сборка самостоятельного
скрипта для `curl … | bash` и сопряжение в «Моих узлах». Основной бинарник Veil,
его протокол и hidden-volume не менялись. Изменения пока не опубликованы.

Последующий [Linux/systemd-прогон](../node-connect-systemd-2026-11-11/README.md)
дополнил эту проверку реальной установкой Veil и выявил два исправленных
пробела. Ниже сохранены границы первоначального Android-прогона.

## Что делает новый путь

Помощник показывает секретный QR для временного HTTPS-сеанса. Приложение
проверяет SHA-256 сертификата до отправки секрета, получает инвентаризацию и
использует существующие сценарии установки, настройки и обновления узла.
Существующий узел добавляется без повторной установки. Поддерживаются
стандартные пути конфигурации установщика xVeil; произвольные пути не ищутся.

Первый клиент закрепляет сеанс за своим случайным идентификатором. Повтор
потерянного запроса сопряжения возвращает тот же доступ; одинаковый запрос
команды не запускает её повторно. Секрет сохраняется отдельно от каталога
узлов, внутри настроек текущей личности. Асинхронные операции проверяют
поколение личности перед продолжением и сохранением результата.

Новые команды принимаются 10 минут по умолчанию, максимум 15 минут. Таймаут
одной команды — до 6 минут; доступ к уже принятому результату имеет короткое
продление. Одновременно исполняется одна команда. Ограничены размер скрипта,
вывод, число квитанций и число TLS-обработчиков. Ctrl+C закрывает доступ и
завершает группу процессов текущей команды. Постоянная служба управления не
устанавливается. Bootstrap содержит точную копию Python-исходника, без
второго скачивания исполняемого кода по плавающей ссылке.

## Проверки

| Проверка | Результат |
| --- | --- |
| Связанные Flutter-тесты | 112 passed, 0 skipped |
| Анализ изменённых Dart-областей | No issues found |
| Python 3.8 и 3.10, Linux | По 10 passed, 0 skipped |
| Настоящий Dart-клиент → Linux HTTPS-помощник | 1 passed, 0 skipped |
| Самостоятельный bootstrap | Генерация и `bash -n` прошли |
| QR из терминала | Независимый декодер восстановил точную ссылку |
| Установка самого помощника | Точные байты; чужой файл, symlink и доступный на запись каталог отклонены |
| Привязки workflow-actions | Проверка immutable pins прошла |

Python-проверки включают эксклюзивное сопряжение, повтор потерянного ответа,
истечение срока, квитанции, конфликт идентификаторов, ограничения вывода,
таймаут и остановку дочерних процессов. Молчащий TLS-клиент не блокирует
остальные запросы. Native live-проверка отдельно доказывает отказ неверному
сертификату до claim, успешный последующий claim другим клиентом,
инвентаризацию, stdout/stderr с ненулевым кодом, усечение вывода и запрет
отправки после смены личности.

## Физический Android-прогон

Blackview BV6600Pro, Android 11, отдельное «Node Connect QA». Использовались
текущие Dart-исходники и профильная Android-сборка; три native-библиотеки
побайтно сверены с опубликованной сборкой приложения. Исходники приложения
зафиксированы хешами до запуска. Новая сборка Rust не выполнялась.

Через настоящий UI открыты «Добавить узел → Подключить по QR», ссылка введена
вручную. Телефон выполнил TLS-сопряжение с изолированным Linux-помощником,
сохранил одну запись узла и отдельный credential, получил инвентаризацию и
открыл штатный экран установки нового сервера. Для доставки к контейнеру
использовался только принадлежащий стенду ADB reverse.

QA-хранилище синтетическое, в памяти: этот прогон проверяет проводку
сопряжения и экранов, а не шифрование или сохранность настоящего контейнера.
Камера не использовалась; QR независимо проверен декодером изображения,
восстановленного из терминальных символов.

## Границы и очистка

Полная установка компонентов на systemd-сервере, оптическое сканирование QR
камерой и доступ через внешний firewall не квалифицированы этим прогоном.
Linux-контейнер не имел установленного Veil; production-сиды не затрагивались.
Недоступность HTTPS-порта или блокировку провайдером этот способ не устраняет.
Исходное пользовательское повреждение при сжатии к этому результату не
относится и не объявляется исправленным.

Тестовый Android-пакет остановлен и удалён, его процесс отсутствует. Удалены
только собственные ADB-привязки. SHA основного APK совпал с исходным. Временный
Linux-помощник остановлен, приглашение удалено; собственный контейнер удалён.
В репозиторий не включены приглашения, секреты, адреса стенда и сырые журналы.
